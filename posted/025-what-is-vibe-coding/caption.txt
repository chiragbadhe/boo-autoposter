What is vibe coding, and should you do it? 🎧👻

AI researcher Andrej Karpathy named it in February 2025: you describe what you want in plain words, the AI writes the code, and you "forget that the code even exists."
You don't read the code. You run it, paste errors back in, and keep prompting until it works.
It's great for quick prototypes and hackathon demos.
But code nobody reviewed can hide security holes and bugs you can't explain in a viva or an interview. For anything real, read and test what the AI writes.
