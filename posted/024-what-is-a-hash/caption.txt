A hash is data’s fingerprint, and blockchains are built on it 🔐👻

A hash function takes data of almost any size and gives a fixed-size code. SHA-256 always gives 256 bits, shown as 64 characters.
Change even one bit of the input and you get a totally different hash.
You can’t work backwards from a hash to the input, and finding two inputs with the same hash is practically impossible.
In a blockchain, every block stores the hash of the previous block. Edit an old block and its hash changes, which breaks every block after it, so the tampering is easy to spot.
