How does your phone read a QR code in a blink? 📷👻

QR means Quick Response. Denso Wave in Japan made it in 1994 to track car parts in factories.
The code is a grid of tiny squares called modules, and the pattern stores your data as bits.
The three big corner squares tell the camera where the code is and which way is up. Smaller patterns help it fix tilt and count rows.
The camera reads the grid, then error correction (Reed-Solomon) repairs missing bits. At the highest level, a code can still be read with about 30% of its data damaged.
The biggest version is 177 x 177 modules and holds up to 7,089 digits.
Tip: a QR code can hide any link, so only scan codes you trust and check where it takes you before paying or logging in.
