Why do arrays start at 0? A, B, C or D? Comment how you did 👇🔢

In C, an array is one block of memory, item after item.
The index isn't a position number. It's how far you move from the start.
The first item is 0 steps away, so it's [0]. The computer finds any item with one sum: start + index × item size.
C got this from BCPL, and in 1982 Dijkstra wrote a famous note, "Why numbering should start at zero". Some older languages like Fortran and COBOL still count from 1.
