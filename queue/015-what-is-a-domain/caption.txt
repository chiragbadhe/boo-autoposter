You type google.com, not a string of numbers. That’s a domain name 🌐👻

A domain name is an easy name that stands in for a website’s IP address.
The .com part is the top-level domain; the name before it is the one you register.
ICANN oversees the system, registries run each TLD, and registrars sell you a name.
You lease a domain for a set time, so renew it or lose it.
